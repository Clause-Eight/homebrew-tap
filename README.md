# Clause Eight Homebrew tap

```bash
brew install clause-eight/tap/ato
```

| Formula | What it is |
|---|---|
| `ato` | Find EU personal data in code, fixtures and logs, confirmed by check digits. [Source](https://github.com/Clause-Eight/ato) |
| `pii-eu` | The 0.2.0 release from before the rename to ATO. Use `ato` instead. |

Formulae install the signed release binaries; `sha256` values come from each release's signed `checksums.txt`.
