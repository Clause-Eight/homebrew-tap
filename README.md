# Clause Eight Homebrew tap

```bash
brew install clause-eight/tap/pii-eu
```

| Formula | What it is |
|---|---|
| `pii-eu` | Find EU personal data in code, fixtures and logs, confirmed by check digits. [Source](https://github.com/Clause-Eight/pii-eu) |

Formulae install the signed release binaries; `sha256` values come from each release's signed `checksums.txt`.
